Who I Am

Catur Septian

@caturseptian · Jakarta, Indonesia

I'm a full stack web developer from Jakarta and have been building web apps since 2016. Most of my work is in HTML, CSS/Sass, and JavaScript on the front end and PHP, Laravel, and MySQL or SQL Server on the back end.

Right now I work on a reporting system for a government agency. I took it over from a previous vendor, with quite a few bugs and outdated libraries, and with my team I've been fixing it and moving business logic out of the database into Laravel code. Before that I worked at a startup in Yogyakarta, building online shops and a school marketplace with Xendit and Midtrans payments, and later managed the IT team there.

I use AI tools while coding, but I check and test the code myself before it goes live. I also try to be careful with personal data, for example by encrypting ID numbers. Lately I've been learning more about data engineering and AI: Python ETL, report automation, and small LLM apps.
